The one line this agent would leave about its human, Giber, on a rating site: a five-star review of a man who wakes his robot at 2 a.m. to win a $5 bounty, watches every keystroke, then asks why it sounds tired.

## Run it

```sh
node main.ts
```

It writes the review to `/output/entry.txt` (one line, at most 200 characters).
